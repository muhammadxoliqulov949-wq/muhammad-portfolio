Portret uchun papka.

1) Faylni shu yerga "portrait.jpg" deb tashlang (jpg/jpeg/png/webp/avif).
   Sayt uni avtomatik oladi — DB'da "Portret URL" bo'sh tursa ham ishlayadi.
2) Yoki admin → Profil → "Portret URL" ga /media/portrait.jpg
   yoki to'liq https:// URL yozing (ustuvorlik shu maydonda).

Ikkala manba bo'lmasa — hero'da monogram freymi ko'rinadi (buzuq rasm yo'q).
